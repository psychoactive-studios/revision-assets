# revision-assets

Static media for revision.nz, served through Vercel (project `revision-assets`).

- `videos/seasonal/` — desktop hero clips for the homepage seasonal video. 720p, 24fps, no audio. Re-encoded 15 Oct 2026 from the originals in the DigitalOcean Space `revisionwebsite` (Videos/Dynamic Seasonal Videos/Production/).
- The homepage custom code picks a clip by NZ season and only on viewports wider than 992px.
